# Tubroom for Hermes Agent

Connects Hermes to the Tubroom MCP server (`https://tubroom.com/mcp`, no sign-in) and adds a skill for answering "which hotel room has a jacuzzi or hot tub?" questions: the exact room to book, its source and check date, and the tubroom.com link.

Tools: search_tub_rooms, romantic_tub_rooms, get_hotel, list_places. All read-only.

More: https://tubroom.com/mcp-server/?utm_source=hermes-catalog
